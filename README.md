# 유튜브 MP3 추출기 1.0.0

유튜브 영상 링크를 입력해 MP3를 추출하고, 지정한 폴더에 저장하는 윈도우 프로그램입니다. 한 화면에 추출 버튼과 저장 버튼이 있으며 자동 저장을 선택할 수 있습니다.

## 실행

배포 파일은 `outputs/YouTubeMP3-1.0.0-win-x64.zip`입니다. 압축을 풀고 `YouTubeMP3/YouTubeMP3.exe`를 실행하세요. 빌드한 프로그램은 `dist/YouTubeMP3/YouTubeMP3.exe`로도 실행할 수 있습니다. 실행 파일만 옮기지 말고 `YouTubeMP3` 폴더 전체를 복사해야 합니다. Python, Node.js, FFmpeg를 별도로 설치할 필요가 없습니다.

유튜브 영상 링크를 입력하거나 붙여 넣고 **MP3 추출**을 누르세요. 추출 완료 후 **저장**을 누르면 지정한 저장 폴더에 영상 제목으로 저장합니다. 저장 버튼은 추출 완료 후 활성화되며, 자동 저장이나 수동 저장을 마친 뒤에도 계속 사용할 수 있습니다. 추출 결과를 임시 보관하므로 재추출 없이 저장 폴더나 메타데이터를 바꾸어 다시 저장할 수 있습니다. 저장에 실패해도 결과를 유지합니다. **저장 위치** 오른쪽의 **폴더 열기**로 현재 지정한 폴더를 탐색기에서 열 수 있습니다.

**자동 저장** 스위치를 켜면 추출 완료 즉시 지정한 폴더에 저장합니다. 처음 실행할 때는 꺼져 있으며, 자동 저장 설정과 저장 폴더는 다음 실행 때도 기억합니다. 같은 이름의 파일이 있으면 `(1)`, `(2)` 순서로 번호를 붙입니다. 저장하지 않은 결과가 있을 때 새로 추출하거나 종료하면 삭제 여부를 확인합니다.

오른쪽 **메타데이터** 패널에서 제목, 아티스트, 앨범, 연도, 트랙 번호, 장르를 편집할 수 있습니다. 음원 추출 영역 오른쪽 상단의 메타데이터 토글로 패널을 접고 펼치며 입력한 내용은 유지됩니다. 처음에는 추출 화면만 표시하고, 토글을 켜면 오른쪽으로 메타데이터 패널이 확장됩니다. 접으면 오른쪽 영역은 완전히 사라지며 추출 영역의 폭은 유지됩니다. 추출 시 제공되는 제목과 음원 정보는 빈 항목에 채워집니다. 사용자가 직접 바꾼 값은 유지하며, 채널명을 아티스트로 추정하지 않습니다. 자동 저장을 켰다면 추출 전에 정보를 입력하세요. 메타데이터 편집은 MP3 내부 태그에 적용하며 파일명은 영상 제목을 사용합니다.

앨범 커버는 **없음 / 유튜브 썸네일 / 이미지 직접 선택** 중 고를 수 있습니다. 기본은 유튜브 썸네일입니다. **이미지 선택** 버튼이나 커버 미리보기 클릭으로 파일을 선택할 수 있고, 탐색기의 이미지 파일 하나를 커버 영역에 드래그해 적용할 수도 있습니다. JPG, PNG, WEBP 등의 이미지는 비율을 유지한 JPEG로 정리해 MP3 안에 포함합니다. 썸네일을 가져오지 못하면 이미지를 직접 선택하거나 **없음**으로 변경해 저장하세요. 실제 앨범 커버를 인터넷에서 자동 검색하는 기능은 없습니다.

저장 시 ID3v2.3 형식으로 메타데이터와 커버를 적용하며, 음원 자체를 다시 인코딩하지 않습니다. 커버 표시 여부는 사용하는 음악 플레이어에 따라 다를 수 있습니다.

구간 추출이나 음질 선택 메뉴는 없습니다. 원본에서 가능한 음원을 받아 MP3 가변 비트레이트 품질 2로 변환합니다. 재생목록 링크가 포함되어도 입력한 영상 한 개만 처리합니다. 진행 중인 라이브 방송, 로그인이나 접근 권한이 필요한 영상은 지원하지 않습니다. 다운로드 권한이 있는 콘텐츠에 사용하세요.

## 개발 및 빌드

Windows x64, Python 3.11 이상, Node.js 22 이상이 필요합니다.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

추출에는 [yt-dlp](https://github.com/yt-dlp/yt-dlp), 변환에는 imageio-ffmpeg에서 제공하는 FFmpeg를 사용합니다. [yt-dlp 공식 EJS 안내](https://github.com/yt-dlp/yt-dlp/wiki/EJS)에 따라 Node.js와 EJS 스크립트를 함께 포함합니다. 유튜브 측 변경으로 추출이 실패하면 `yt-dlp[default]`의 버전을 함께 업데이트하고 다시 빌드해야 할 수 있습니다.

태그에는 [Mutagen](https://mutagen.readthedocs.io/en/latest/api/id3_frames.html), 이미지 처리에는 Pillow, 윈도우 파일 드롭에는 [TkinterDnD2](https://github.com/Eliav2/tkinterdnd2)를 사용합니다. 빌드에 TkDnD 네이티브 파일도 포함합니다.

설정은 `%LOCALAPPDATA%\YouTubeMP3Extractor\settings.json`에 보관합니다. 추출과 변환은 Windows 임시 폴더에서 진행하며, 저장 버튼을 누르거나 자동 저장을 켰을 때만 지정한 저장 폴더에 MP3를 만듭니다. 추출 결과는 다시 저장할 수 있도록 보관하고, 새 결과로 교체하거나 정상 종료할 때 정리합니다. 강제 종료하거나 전원이 꺼지면 시스템 임시 폴더에 `youtube-mp3-`로 시작하는 임시 폴더가 남을 수 있습니다.
